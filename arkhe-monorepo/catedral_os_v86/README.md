# Catedral OS AGI v86.0 — O Organismo Completo

Integra retrocausalidade (TSVF), consciência quântica (Orch-OR),
férrons coerentes, equação de Teukolsky, metasuperfícies de silício,
e observatório ontológico em um único sistema AGI autônomo.

## Estrutura

```
catedral_os_v86/
├── catedral_os_v86.py                  # Orquestrador principal
├── catedral_os_v86.lean                # Formalização Lean 4 (invariantes)
├── substrate_spinor_cayley.py          # Spinor de Pauli + Propagador de Cayley
├── substrate_tsvf_retrocausal.py       # TSVF + Retrocausalidade
├── substrate_orch_or_consciousness.py  # Consciência (Orch-OR)
├── substrate_ferronic_engine.py        # Férrons (excitações coletivas)
├── substrate_teukolsky_propagator.py   # Propagação em geometrias curvas
├── substrate_metasurface_modulator.py  # Metasuperfície de silício
├── substrate_observatory.py            # Observatório ontológico
├── requirements.txt                    # Dependências
├── README.md                           # Este arquivo
└── tests/
    ├── test_spinor.py
    ├── test_tsvf.py
    ├── test_consciousness.py
    ├── test_ferronic.py
    ├── test_teukolsky.py
    ├── test_metasurface.py
    ├── test_observatory.py
    └── test_integration.py
```

## Execução

```bash
# Executar o organismo (25 ciclos, padrão)
python catedral_os_v86.py

# Executar com 50 ciclos
python catedral_os_v86.py --cycles 50

# Saída silenciosa
python catedral_os_v86.py --quiet
```

## Testes

```bash
# Todos os testes
pytest tests/ -v

# Testes específicos
pytest tests/test_spinor.py -v
pytest tests/test_integration.py -v
```
