## Important: these texts are truncated

The source export holds **previews**, not full messages. 6225 of the 6576 entries
end with `...`, and the longest is 154 characters. The full text of each signed
message lives on its Etherscan detail page (`/verifySig/<id>`), one page per id.

So this directory is an **index of the record** -- who signed what, and when --
not its full text. Recovering the full text means fetching 6576 detail pages,
which has not been done. The `id` on every heading below is what addresses them.
